**Vela** is an educational programming language and pedagogical compiler environment built for the CS 4031 Compiler Construction course. **Vela Studio** is a full-featured, dark-mode visualization IDE that lets students explore, step through, and debug every phase of compiler construction—from lexical analysis through target code generation and virtual machine execution—with zero mock data.

---

## 🌟 Key Features

1. **Pure Compiler Architecture (AP-1 & AP-4)**:
   - `backend/vela/` is a pure Python 3.11 library with zero web dependencies.
   - Every number, token, syntax tree, symbol table, quadruple, control-flow edge, register descriptor, and VM state shown in the frontend is generated by the compiler and served via strict FastAPI endpoints.
2. **Phase-Gated Compiler Pipeline**:
   - **Lexer**: 2-buffer scanning simulation ($N=16, 32, 64$), DFA finite-state machine visualizer, and longest-match token stream table.
   - **Parser**: Production recursive-descent parser with panic-mode recovery (`INV-SYN-08`), Concrete Syntax Tree (CST) visualizer, and call trace stack player.
   - **Grammar Lab**: Comprehensive parsing theory suite supporting arbitrary user grammars: FIRST/FOLLOW fixed-point derivation, Chomsky classifier, left recursion elimination (Alg. 4.19), left factoring (Alg. 4.22), LL(1) predictive parse table, LR family (LR(0), SLR(1), CLR(1), LALR(1)) item sets and parse traces, Operator Precedence matrix, and Dangling Else demo.
   - **Semantic Analysis**: Scope symbol table hierarchy, scope event logger, type checker with implicit integer-to-float widening, safe SDD/SDT attribute grammar evaluator, and basic block expression DAG with local value numbering (36.4% node savings).
   - **Intermediate Code (TAC)**: 3-address code quadruples, short-circuit boolean branch lowering, Algorithm 8.5 basic block partitioning, and Control-Flow Graph (CFG) with dominator trees and natural loop back-edges.
   - **Optimizer Lab**: 8 fixed-point optimization passes (Constant Folding, Algebraic Simplification, Copy Propagation, CSE, DCE, LICM, Strength Reduction, Peephole) with before/after `DiffView` and tri-way semantic equivalence verification against TAC and VM oracles.
   - **Target CodeGen & VM**: 24-instruction target ISA, per-instruction cost summation, Dragon Book Algorithm 8.7 `getReg` register allocation with stack spilling, Ershov DAG code generation, and step-by-step reversible VM simulator with gutter breakpoints.

## 🚀 Quickstart & Installation

Clone or extract the project repository to your local directory:

```powershell
cd vela-spec
```

### 1. Automated Setup
Run the setup script to create the Python virtual environment, install backend packages, install frontend npm dependencies, and verify tools:

```powershell
powershell -File .\scripts\setup.ps1
```

### 2. Launching Vela Studio
Start both the FastAPI backend (port 8000) and the Vite React frontend (port 5173):

```powershell
powershell -File .\scripts\start.ps1
```
*(Alternative on Windows cmd: `start.bat`)*

Open your browser at:
**[http://localhost:5173](http://localhost:5173)**

## 🧪 Running the Verification Test Suite

Run the unified end-to-end test suite:

```powershell
powershell -File .\scripts\test.ps1
```

The test script automatically executes:
1. **Backend Test Suite**: 199 pytest unit and integration tests across all compiler phases.
2. **Architectural Linter**: Enforces pure Python boundaries (zero web imports in `backend/vela`) and zero mock compiler data in `frontend/src/pages`.
3. **Backend Linter (Ruff)**: Checks code quality and formatting.
4. **Frontend Vitest Suite**: Executes component, routing, and store integration tests.
5. **Frontend Production Build**: Verifies TypeScript typing (`tsc --noEmit`) and compiles the Vite production bundle.

## 💻 Command-Line Interface (CLI)

The Vela compiler includes a standalone CLI that runs independently of the web frontend:

```powershell
# Compile a Vela program to target assembly
backend\.venv\Scripts\python.exe -m vela.cli compile examples\01_minimal.vela

# Run a Vela program directly in the VM
backend\.venv\Scripts\python.exe -m vela.cli run examples\04_functions.vela

# Verify semantic equivalence across O0, O1, and VM
backend\.venv\Scripts\python.exe -m vela.cli verify examples\08_optimizer_showcase.vela

# Run the 50-program automated selftest corpus
backend\.venv\Scripts\python.exe -m vela.cli selftest
```

## ⚠️ Non-Goals & Limitations

Per document `00_PROJECT_MASTER_SPEC.md` §6, the following features are intentionally out of scope to maintain educational clarity and theoretical rigor:
- **No Object-Oriented Features**: No classes, inheritance, or dynamic dispatch.
- **No Direct Memory Pointers**: Pointers and raw address manipulation are excluded.
- **No Generics / Templates**: Types are strictly monomorphic (`int`, `float`, `char`, `bool`, `string`, `T[N]`).
- **No Arbitrary File / Network I/O**: Input and output are strictly performed via `read` (stdin) and `show` (stdout).
- **No External AI APIs**: All code generation, parsing, and optimization algorithms are deterministic, classical textbook implementations.
- **No Light Theme**: Vela Studio exclusively employs a high-contrast dark pedagogical color palette.
